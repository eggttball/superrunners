# Super Runners Implementation Plan

**Goal:** 可操作並可匯出完整全國資料的臺灣國中百米遊戲。
**Architecture:** Vue Vapor 介面、背景 Worker 初始化全國學生、IndexedDB 分表保存、解析速度積分驅動 SVG 像素角色。
**Tech Stack:** Vue 3.6.0-rc.8 Vapor、Vite 8.3、JavaScript、CSS、SVG、IndexedDB。
**Spec:** docs/superpowers/specs/2026-09-18-superrunners-design.md

## 使用者優先指示

學生全部使用復古像素人物。略過所有測試；未新增測試檔案，未執行自動或瀏覽器操作測試。只進行正式打包。

## 完成狀態

- [x] 官方名錄：教育部 115 學年度 740 所國中、230 所附設國中部，全臺 22 縣市、合計 970 所。附原始快照、來源文件與可重建腳本。
- [x] 資料生成：全國學生首次一次性生成，三年級、合理班級人數、固定資料、唯一 2–3 字母 + 7 數字學號、完整個人能力與四層排名。
- [x] v2 校園結構：年級名稱為一年級、二年級、三年級；每年級 8–12 班，每班固定保存初始化抽取的班服顏色。
- [x] v2 成績模型：各班 14–16 秒占 50–65%，13 秒級與 16 秒以上較少，12 秒、11 秒、10 秒級依序稀有；每次比賽另有百分之一秒級微幅波動。
- [x] 跑道與人物：36.5m 內緣半徑、36.8m 測量線半徑、1.22m × 8 道、100m 延伸直線；完整鳥瞰 SVG 操場及一致像素學生。
- [x] 百米公式：10 + softplus 下限模型；身高／體重／能力的單調影響、零速加速、末段耐力衰減與一致完賽時間。
- [x] 學校與隊伍：縣市搜尋、收藏學校、關注田徑隊、學生編輯、班／年／校名冊排名、全國個人排名、歷年獎牌。
- [x] 比賽流程：最多 8 班、每組最多 8 人、逐班進行；倒數、暫停、播放速度、結果、紀錄。完賽與全班獎牌原子保存，失敗可重試。
- [x] 本機存檔：Worker 初始生成、IndexedDB 完成標記與初始化擁有者、序列化變更與匯出完整 JSON。
- [x] 首頁：像素巡跑、合成音樂與靜音、浮動選單、未開放功能停用。
- [x] 文件：README、公式／跑道文件、名錄來源與 schema。
- [x] 正式打包：npm run build 成功，產生 dist；未執行測試。

## 範圍判定

代表隊按照需求後段「不可手動指定、自動產生機制下一階段」處理：保留隊伍類型與欄位、顯示能力，不提供手動組隊或自動選拔。初始獎牌為空，校內各班百米前三名由實際遊戲賽事累積。未參賽學生以固定預估時間排名並在 UI 標示。
