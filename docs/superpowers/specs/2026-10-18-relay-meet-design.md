# 全校大隊接力設計

## 已確認規則

- 每班 16 人，每人名義 100m，接力棒全程 1600m，完整 400m 操場逆時針奔跑。
- 選班時 2～8 班為單場友誼賽，不記錄正式賽事或個人最佳；不選班時全校正式淘汰賽，自動接續。
- 班級依年級、班號排序，連續每八班一組，跨年級可同場。2～4 隊取前一、5～6 隊取前二、7～8 隊取前三，只有一班直接輪空。下一輪晉級班級重新依年級班號排序分組。
- 依個人最佳（沒有時依百米預估）選前 16。第一棒最快，末棒第二快，中間 14 人隨機排列；保存排名簽章及棒次。下一屆開始時前 16 排序改變才重排，同一屆各輪固定名單。
- 第一棒由 400m 階梯式分道起跑線出發；前三棒分道，第四棒通過累積 320m 搶道弧線及角錐後漸切內道。
- 每 100m 交棒點附近有 30m 接力區（交接點前 10m 至後 20m）。接棒者只能在區內預跑、接棒；交棒者預跑和跑過區域的重疊不增加棒的全程。
- 交棒者速度、體力、肌耐力高時偏向較晚交棒；接棒者速度、爆發力高時偏向較早交棒。雙方技巧高時交棒掉速與重疊時間較少。
- 第五棒依初始道次排列；第六棒起以前棒通過本次接力區前準備線的先後由內向外排隊，前隊交棒完成後其他等候者平滑補位。搶道後的持棒者沿內道奔跑，並保留固定且平滑的視覺偏移，減少重疊；近距離超車與交棒仍允許短暫交疊。
- 正式賽保存班級總秒數、16 人快照、棒次、分段及交棒資料，JSON 匯出及雲端同步。接力分段不更新個人百米最佳及排名。
- 最新冠軍班獲「風速小班」，新一屆替換當前稱號，歷屆冠軍保留。歷程樹由第一輪往上至決賽，每場展示班級、總秒數、晉級狀態。
- 背景比賽不中斷，暫停/繼續、1/2/4/8/16x，預設 1x。本機保存目前組別、已抽取速度曲線與進度；重新載入可從保存位置繼續。友誼賽進度可保存本機但不進正式歷史或雲端。

## 實作分工與界面

`relay-rules.js` 處理排名簽章、棒次及淘汰賽；`relay-physics.js` 建立可序列化 16 棒速度與交棒計畫並讀取即時狀態；`relay-track-geometry.js` 提供完整操場座標、起跑及搶道線。獨立 `relay-meet.js` 控制器持有背景時鐘，透過 game.js 安裝保存依賴，不綁定 Vue 元件生命週期。

`RelayRaceView.vue` 顯示完整操場、各班目前棒次/名次/時間、接棒預跑與減速跑者及控制；`RelayMeetSummary.vue` 顯示樹狀歷程。`RelayTitleBadge.vue` 在學校班級及比賽班級卡顯示稱號。

IndexedDB 版本升為 6，增加 relayMeets、relayRaces、relayLineups 三個 store。`relayChampions` 為 metadata，`relayMeetProgress` 僅本機，完整資料不重生。Realtime Database 新增 dynamic/relayMeets、relayRaces、relayLineups、relayChampions 路徑，全部維持管理者存取規則。正式組別使用固定 race ID 及 outbox，完成賽果與稱號為同一保存/上傳動作。
