# 學校名錄來源

本版使用教育部統計處 **115 學年度（2026–2027）** 名錄，於 **2026-09-18** 擷取。共 **970 所**，含 **740 所國民中學**與 **230 所附設國中部**，涵蓋臺灣全部 **22 縣市**。兩份名錄的學校代碼沒有重複。

教育部公告：[115 學年各級學校名錄及異動一覽表](https://depart.moe.edu.tw/ED4500/News_Content.aspx?n=63F5AB3D02A8BBAC&sms=1FF9979D10DBF9F3&s=52D3798D5069E231)。該公告分別列出「國民中學」及「附設國中部」下載，因此完全中學的國中部有獨立且可追溯的官方來源，沒有自行推測或補造學校名稱。

| 來源 | 可重建的 JSON | 同學年度 XLSX | 筆數 |
| --- | --- | --- | ---: |
| 國民中學名錄 | [j1_new.json](https://stats.moe.gov.tw/files/opendata/j1_new.json) | [115/j1_new.xlsx](https://stats.moe.gov.tw/files/school/115/j1_new.xlsx) | 740 |
| 附設國中部名錄 | [aj_new.json](https://stats.moe.gov.tw/files/opendata/aj_new.json) | [115/aj_new.xlsx](https://stats.moe.gov.tw/files/school/115/aj_new.xlsx) | 230 |

官方 JSON 包含多個學年度；匯入時只選 `學年度 === "115"`。`scripts/school-sources/115-j1_new.json` 與 `115-aj_new.json` 保留選取年度的所有原始欄位，並記錄下載網址、擷取時間、完整回應與選取資料的 SHA-256。原始 JSON 中的學校名稱、六位數代碼、地址、網址均原樣保存於應用程式資料，地址包含教育部登載的郵遞區號。只去除縣市名稱前面的官方數字標記，例如 `[01]新北市` 轉成 `新北市`，並合併同名縣市的舊行政區標記。

## 範圍與限制

- 本版範圍為上述兩份國中名錄；未加入另列的籌備處、進修部、特殊教育學校、海外臺灣學校或非學校型態實驗教育機構名錄。在這兩份國中名錄內的實驗學校照實保留。
- 附設國中部保留教育部完整名稱（例如「國立華僑高級中等學校附設國中」），沒有把高中全校當成國中，也沒有重新命名。
- 官方來源有 3 所學校網址為空字串：`193529` 市立南興國中、`091506` 私立福智實驗國中、`033301` 市立承光華德福實驗高中附設國中。本版保留空值，沒有猜測網址；其他網址也保留官方 HTTP／HTTPS 記載，未逐站確認可連線。
- 學校名錄為該學年度的官方快照，未主張即時反映公告後的停辦、更名或異動。升級學年度時應重新查閱教育部公告。
- **只有學校名錄是真實資料。** 遊戲中的班級、人數、學生姓名、身體數值、能力、隊伍與賽事成績均為虛構，不能據此推算真實學校學生或競賽情況。

## 重新產生

需求為 Node.js 22+，不需要額外套件。輸出檔案為 `src/data/schools.js`，提供 `catalog` 與 `catalogSource` 兩個具名匯出。遊戲執行時直接使用此檔，不依賴教育部即時連線。

```sh
# 從兩份官方 JSON 重新下載，固定選取 115 學年度。
node scripts/fetch-schools.mjs

# 從版控中的原始年度快照重建；保留原擷取時間。
node scripts/fetch-schools.mjs --offline

# 已用 curl 等工具下載時，資料夾須含 j1_new.json、aj_new.json。
node scripts/fetch-schools.mjs --input-dir /path/to/downloads
```

匯入腳本會在寫入前檢查資料欄位、年度、代碼重複及 22 縣市涵蓋率；來源不完整時停止，不產生虛構備援資料。快照載入時會比對選取資料的 SHA-256。若改用新學年度，先調整腳本中的 `YEAR`、公告網址及學年度文字，再更新本文件的筆數與限制。

本次依使用者要求沒有新增或執行測試套件；上述筆數與涵蓋率來自實際匯入與來源內容檢查。
