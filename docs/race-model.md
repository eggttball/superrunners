# 百米模擬與跑道

這是虛構國中生的遊戲模型，不是運動醫學預測。每位學生的初始能力固定；性別、姓名及校隊身分不直接改動成績。身高單位是公分、體重單位是公斤，五項能力皆為 1–10，年級為 1–3。

## 完賽時間

`predict100(student)` 回傳未四捨五入的秒數。以身高 165、體重 55、五項能力 5.5 為中心，先計算：

```text
z = 6.5
    − 0.024 × (身高 − 165)
    + 0.038 × (體重 − 55)
    − 0.160 × (年級 − 2)
    − 0.340 × (爆發力 − 5.5)
    − 0.105 × (耐力 − 5.5)
    − 0.105 × (體力 − 5.5)
    − 0.160 × (力量 − 5.5)
    − 0.180 × (技巧 − 5.5)

時間 = 10 + log(1 + exp(z))
```

實作使用數值穩定的 softplus，作為個人綜合能力排序。公式中的負號代表該數值增加會縮短時間，體重項的正號代表其他值相同時體重增加會拉長時間。初始化時，每個班獨立抽取一條分布：14–16 秒占約 50–75%，班級中心另有 ±0.25 秒差異；年級每增加一年，中心約快 0.20 秒。13–14 秒及 16 秒以上較少，12–13 秒更少，11–12 秒極少。班內學生先依公式排序，再配對到分布中的時間，因此身體與能力較好的學生仍取得較快基準。10–11 秒選手在學校層級抽取，多數學校為零，少數為一位，最多兩位。

實際比賽以學生的 `baseline100` 為中心，抽取三個均勻亂數形成窄鐘形波動：`(r1 + r2 + r3 − 1.5) × 0.20` 秒，再取到百分之一秒。總波動最多約 ±0.30 秒，多數遠小於此值；兩位相同能力的學生可能同秒，也可能只差幾個百分之一秒。

爆發力另作為突破潛力。令 `p = (爆發力 − 1) / 9`，單場突破機率是 `0.03 + 0.22p`，約為 3–25%。觸發時，成績會嘗試比目前最佳快 `0.02 + random × (0.06 + 0.38p)` 秒，但生涯突破下限不超過 `baseline100 − (0.10 + 0.55p)`，且所有成績仍不得低於 10.01 秒。每組只建立一次結果，重播動畫或存檔重試不會再抽取。

## 加速與末段速度衰減

`createSprintProfile(student, random = Math.random)` 回傳不可變的 `{ time, accelerationDuration, fatigueStart, fatigueLoss, peakSpeed, finishSpeed, runoutDuration }`。

加速時間：

```text
A = 0.75 + 3.4 × exp(
      −0.004 × (身高 − 165)
      +0.006 × (體重 − 55)
      −0.140 × (爆發力 − 1)
      −0.045 × (力量 − 1)
      −0.025 × (技巧 − 1)
    )
```

其他數值相同時，較高、較輕，或爆發力、力量、技巧較高的跑者，更早到達最高速度。跑者由零速起跑，速度在加速結束時平滑接上最高速度。

令 `r = (耐力 + 體力 − 2) / 18`，開始衰減時間 `F = time × (0.58 + 0.14r)`，終點的速度損失比例 `L = 0.36 − 0.29r`。低耐力、低體力的跑者更早衰減，且末段速度損失較大。

未正規化速度：

```text
0 ≤ t ≤ A:     2(t/A) − (t/A)²
A < t ≤ F:     1
F < t ≤ time:  1 − L((t−F)/(time−F))²
```

整段解析積分為 `area = time − A/3 − L×(time−F)/3`，最高速度設為 `100/area`，因此跑者在 `time` 時恰好抵達 100 公尺。加速段末端的積分為 `2A/3`，巡航段從同一距離接續；衰減段在 `F` 從巡航距離接續，因此位置、速度在兩個交界都連續。

過線速度是 `finishSpeed = peakSpeed × (1 − L)`。過線後再以線性減速跑 `D = 2.8 + 0.4 × (1 − r)` 秒；令 `q = clamp((t − time) / D, 0, 1)`，追加距離為 `finishSpeed × D × (q − q²/2)`，速度為 `finishSpeed × (1 − q)`。最後 32% 的減速時間同步淡出。正式成績仍是抵達 100 公尺的 `time`，延伸動畫不計入秒數。

## 真實比例與像素跑者

`track-geometry.js` 以公尺作為 SVG 座標。內緣半徑 36.5 公尺，第一道測量線離內緣 0.30 公尺，因此測量半徑為 36.8 公尺；兩段直道各長 `(400 − 2π×36.8)/2`，約 84.389 公尺。八道各寬 1.22 公尺。

兩個圓心為 `(0,0)` 與 `(直道長,0)`。100 公尺位於下方直道，起點 `x = 直道長 − 100`，終點 `x = 直道長`，向左延伸約 15.611 公尺。`sprintPoint(distance,lane)` 保留每位跑者的道次；`lapPoint(progress,lane)` 供首頁逆時針巡跑使用。測量線與跑者沿道中央的位置是不同概念，不將道中央誤當成官方 400 公尺測量線。

`Track.vue` 的 props 為 `runners`（`{id,name,gender,height,weight,lane,distance,speed,opacity,color}` 陣列）、`animated`（預設 true）、`raceMode`。首頁沒有指定跑者時顯示完整橢圓跑道與巡跑；`raceMode=true` 會改用獨立 viewBox，只裁切八道百米直線、起終點標記與終點後減速區，使人物約放大為完整場視角的兩倍。`animated=false` 可暫停步態，位置由傳入距離決定，元件不自行推進比賽。人物以直立側視像素跑姿顯示，手腳步頻由即時速度決定；即時名次顯示在賽道下方的選手卡，不覆蓋人物。

`PixelRunner.vue` 可供所有學生卡片與名單重用：`seed:string`（決定固定外觀）、`gender:string`（`男` 或 `女`，控制身形與髮型輪廓）、`height`、`weight`、`speed`、`backdrop`、`color:string`（只控制班服上衣）、`running:boolean`、`size:number|string`（預設 40）、`label:string`（可選替代文字）。身高將角色高度縮放至 0.93–1.05 倍，體重將寬度縮放至 0.90–1.18 倍。學號種子會從五階膚色、直髮或捲髮、眼鏡、個人褲色及鞋色中固定取值；女性另有短髮與長髮。一般頭像使用淺色底襯托深色頭髮，賽道角色關閉底色。像素身體與四肢使用原生 SVG，跑步採兩幀步態，遵守減少動態效果偏好。

依使用者指示，本階段沒有建立或執行自動化測試。
